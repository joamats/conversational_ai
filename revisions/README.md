# Revisions

Additional analyses added during the revision of the paper. Each folder has its own README.

| Folder | Content |
|---|---|
| [`exp1/`](exp1/) | Human validation of the LLM judge used for parameter adherence and clinical fidelity: annotation app, analysis and figures. |
| [`exp2/`](exp2/) | Clinical fidelity across personas, re-evaluating the conversations of the persona fairness experiment. |

`exp1/` runs on its own from its folder. `exp2/` uses `eval/` and `fairness/` from this repository and is run from the repository root.

The study data behind these analyses is not included; see each folder's README.
